# Retail Sales Data Analysis

## Overview

This project focuses on exploring retail sales data through data cleaning, exploratory data analysis (EDA), and SQL-based analysis.

## Objectives

- Understand the structure and quality of the dataset.
- Perform data cleaning and preprocessing.
- Explore sales and profit patterns.
- Extract meaningful business insights.
- Practice Python and SQL for data analysis.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PostgreSQL
